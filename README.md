# Generador de Itinerarios Turísticos Personalizados

## Descripción
Aplicación MVP para agencias de turismo en Cartagena que permite crear clientes, itinerarios y generar PDFs de forma rápida.

## Estructura del proyecto
- backend: API en Node.js + Express + TypeScript + Prisma + Supabase
- frontend: React + Vite + TypeScript + Tailwind

## Variables de entorno
Copiar el archivo backend/.env.example a backend/.env y completar las credenciales de Supabase.

## Comandos recomendados
- Backend: npm install && npm run dev
- Frontend: npm install && npm run dev
